# Imagist

> A minimalist, in-browser image cropper, resizer, size compressor, and format converter.

---

## Features

- **Format Converter**: Instant in-browser conversion between **JPG, PNG, WEBP, and PDF**.
- **Resize & Compress**:
  - Custom width and height (in pixels or centimeters).
  - Target file size (specify exact Min and Max KB limits).
  - Export to JPG, PNG, WEBP, or PDF.
- **Interactive Cropper**: Smooth zoom, rotation (90°), horizontal flip, and locked aspect ratios.
- **Enhancement Filters**:
  - Clean Signature: Whitens background paper shadows and darkens ink strokes.
  - Auto Enhance: Balances exposure and contrast.
  - B&W / Grayscale.
- **Name & Date Stamp**: Optional bottom banner for candidate name and capture date.
- **100% Client-Side Privacy**: All processing runs locally inside your browser using HTML5 Canvas. Zero uploads, zero tracking.

---

## Local Development

```bash
python -m http.server 3000
```
Open `http://localhost:3000` in your browser.
